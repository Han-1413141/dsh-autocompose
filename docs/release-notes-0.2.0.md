# dsh-autocompose 0.2.0

首个公开版本。完整功能与安装说明见 [README](https://github.com/Han-1413141/dsh-autocompose#readme)，更新记录见 [CHANGELOG](https://github.com/Han-1413141/dsh-autocompose/blob/master/CHANGELOG.md)。

## 安装

```powershell
dsh plugin --profile web add dsh-autocompose@0.2.0 --save-exact --ignore-scripts
```

两个插件的源码、构建、测试和版本分别维护。本次实际验证 DSH 0.2.0-rc.2；集成模型使用本地替身。

附件提供与 npm 发布相同的安装包。
